# Aurora Game Booster

Aurora Game Booster is a transparent Windows 11 gaming setup and verification tool
designed by Benny Cohen.

Aurora shows proposed changes before applying them, backs up supported settings,
applies only selected optimizations, verifies the result, and provides undo where
supported. It does not promise a guaranteed FPS increase.

## Release status

See [DEPLOYMENT_STATUS.md](DEPLOYMENT_STATUS.md) for the current release gate.

## What Aurora covers

- Windows Game Mode and capture settings.
- Desktop visual-performance preferences.
- RAM/process monitoring and manual cleanup tools.
- NVIDIA global-profile guidance.
- AMD Adrenalin guidance without undocumented registry writes.
- Backup, verification, explanations, and undo for supported changes.
