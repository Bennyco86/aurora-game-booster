A controlled workflow

Four steps, with evidence at every stage.

  1. 01

    Scan

    Read current Windows, GPU, RAM, and process state.

  2. 02

    Back up

    Capture supported settings before writing changes.

  3. 03

    Apply

    Apply selected missing optimizations, not a mystery preset.

  4. 04

    Verify

    Compare current values with targets and undo when supported.

Windows

See the exact setting before Aurora changes it.

Game Mode, capture settings, desktop effects, process priority, and supported user-level optimizations are separated into automatic, manual, and experimental actions. The planned Advanced Store candidate adds action-specific UAC for HAGS, Ultimate Performance, and supported NVIDIA automation.

NVIDIA

Verified settings can be automated in Advanced; unsupported controls remain transparent and manual.

AMD

Adrenalin recommendations stay manual when driver interfaces are undocumented.

Memory

RAM tools explain the cache tradeoff instead of promising more physical RAM.

Trust is a feature

Aurora will not ask you to turn protection off just to install it.

Release checks require a versioned artifact and matching SHA-256.

The Store edition does not include controls that disable Windows security features.

Distribution will use the Microsoft-certified Store package, not an unsigned mirror.
