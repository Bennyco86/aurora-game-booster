# Aurora Deployment Status

Updated: 2026-07-31

## Current state

Aurora Game Booster is **live on the Microsoft Store**:

- Listing: <https://apps.microsoft.com/detail/9N5KLCCP3G82>
- Version: `1.0.18.0` (Advanced edition), x64, Windows 11 build 22000 or later.
- Price: USD 9.99 one-time purchase (shown in your local currency). No
  subscription.
- Microsoft Store certification: passed, including approval of the
  `runFullTrust` and `allowElevation` restricted capabilities after review.
- Malware scan: Microsoft case completed with no malware detected by cloud or
  client scanning.

The Microsoft Store listing is the only supported way to obtain Aurora. The
older direct installer `1.0.17` remains on distribution hold and was never
released.

## Safety

Do not disable Smart App Control, Microsoft Defender, or another security
control to install Aurora. Do not use installers or packages from mirrors —
if it did not come from the Microsoft Store listing above, it is not Aurora.

Release notes, known issues, policies, and support information are published
in this repository.
